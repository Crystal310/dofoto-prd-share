§3 功能详述
3.1 Skin Tone 肤色调整
单图编辑模块新增 Skin Tone 工具，通过端侧 AI 对人像皮肤区域进行肤色预设 + 强度调节。
页面说明
屏 1：菜单栏入口
页面内容
· 底部工具栏新增 Skin Tone 图标，位于 Hair 与 Body 之间 · 升级版本的老用户和新用户，图标右上角显示红点
交互说明
· 用户点击 Skin Tone 图标 → 执行人脸识别 · 单人脸 → 直接进入 Skin Tone 编辑页（屏 2） · 多人脸 → 进入人脸选择页，用户选中目标人脸后进入编辑页 · 未检测到人脸 → toast 提示，不进入编辑页 · 点击后红点消失
屏 2：Skin Tone 编辑页
页面内容
· 底部效果卡片横滑区域，首位 Original（默认选中），后接 8 种肤色卡片 · 底部工具栏：× 取消 / ✓ 应用
交互说明
· 点击肤色卡片 → 选中并预览，单选互斥 · 点击 × → 放弃改动，返回工具栏 · 点击 ✓ → 应用效果，记录撤销点
屏 3：应用效果 · 滑杆与对比
页面内容
· 选中肤色效果后，滑杆可调节强度（0–100） · 右下角出现对比工具图标
交互说明
· 拖动滑杆实时调整效果强度 · 长按对比工具 → 显示原图；松手 → 恢复效果 · 点击 ✓ → 应用效果并记录撤销点
重置
· 切换肤色预设 → 展示上一次调整的强度值；如未调节过则展示默认值 80 · 选回 Original → 清除所有肤色效果，恢复原图
效果说明
肤色预设 · 8 种预设（由浅到深）：Porcelain / Rose / Ivory / Beige / Caramel / Olive / Tan / Bronze · 橙色标注为 Pro 会员解锁效果；免费效果：Porcelain / Beige / Caramel · 点击 Pro 效果 → 直接展示应用效果预览，滑杆上方弹出黄色 Pro 解锁卡片（同 Face 会员解锁样式） 技术实现 · 端侧 SDK @陈灿跃 · 云端放置皮肤分割和遮挡分割模型 @赵海宾 首页效果入口 · Retouch 和 Face 之间新增 Skin Tone 入口，展示 New 黄色标签
3.2 IAP 节日促销云端配置
建立通用的 IAP 节日促销框架，促销主题、折扣力度、促销时间、海报素材等全部由云端配置下发。首次上线主题：万圣节。
页面说明
屏 1：促销订阅页
触发条件
· 促销期间所有原弹 Pro 页的时机 · 新用户经过开屏广告后 · 老用户升级启动后 · 点击设置页促销 banner · 点击商店 event
页面内容
· 顶部节日皮肤，覆盖在旧 IAP 轮播图上方（云端下发素材） · 倒计时（剩余 ≤ 72h 时显示，格式 时:分:秒） · 年订阅 / 周订阅选项（默认选年订阅） · 订阅按钮（Continue） · 底部隐私条款（同线上 Pro 页） · 顶部关闭按钮 × ，Q&A按钮？
交互说明
· 用户点击 Continue → 调起 Google Play 支付流程 · 点击 × → 关闭促销订阅页 → 按规则判断是否弹打折弹窗 · 倒计时归零 → 页面自动回归常规 Pro 购买页样式
屏 2：打折弹窗
触发条件
· 促销期间第 3、5、8、10 次打开后弹出 · 商店 event 入口：先弹促销订阅页，关闭后弹出打折弹窗（本次节日无 event，后续节日使用）· 弹窗优先级：若打折弹窗与上新弹窗在同一次 app 打开中同时命中触发条件，优先弹出促销弹窗，打折弹窗顺延到下一次进入 app 时补弹
页面内容
· 弹窗素材（云端下发） · 折扣价信息 · 订阅按钮 · 关闭按钮
交互说明
· 点击弹窗 → 跳转促销订阅页（IAP 页） · 消失逻辑同线上弹窗 · 促销已过期时同样展示过期 toast
屏 3：设置页促销 Banner
触发条件
· 促销期间，非 Pro 用户进入设置页时展示
页面内容
· 设置页顶部新增促销 banner（素材云端下发）
交互说明
· 用户点击 banner → 跳转促销订阅页 · 促销结束后恢复为原来 IAP 卡片
业务逻辑
促销期间的订阅流程替换 · 活动期间，云端配置到促销时，IAP 页展示带节日皮肤的促销订阅页；未配置到促销时，使用旧版 IAP 页 · 促销订阅页替代常规 Pro 购买页：所有原弹 Pro 页的时机（开屏后自动弹出、设置页 Pro 入口、首页 Pro 图标等）均改为展示促销订阅页 · Pro 用户：不展示上述促销内容 倒计时规则 · 促销订阅页的倒计时仅在促销剩余时间 ≤ 72 小时时显示 · 支持云端配置活动日期，本次活动开始日期 10月29日0点-11月2日0点 · 倒计时结束（促销到期）→ 所有促销板块回归常规状态：订阅页恢复为 Pro 购买页、设置页 banner 恢复、保存页卡片消失、打折弹窗不再触发 促销过期兜底 · 倒计时结束后，用户点击订阅按钮（continue）→ 不弹付款弹窗，展示 toast：「The offer has expired. More deals coming soon!」 促销定价规则 · 促销折扣价格按用户当前国家显示，基于该国原价进行折扣计算（如年订原价 $15.99，30% off → 折后 $11.99）
3.3 UI 优化 + 包体积瘦身
贴纸素材加载占位图优化 + 清理包内冗余素材，减小安装包体积。
业务逻辑
贴纸素材占位图 · 所有贴纸分类 tab 使用统一的占位图样式 · 素材缩略图加载完成前，展示占位图占位 · 加载完成后占位图被素材缩略图替换，无闪烁 · 加载失败时占位图保持展示（不出空白） 包体积瘦身 · 清理包内冗余素材（未使用的图片、重复资源等），减小安装包体积
