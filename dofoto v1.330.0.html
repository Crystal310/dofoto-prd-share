§3 功能详述
3.1 首页上新弹窗
当前 App 上新效果素材后，用户缺乏感知渠道，新素材曝光依赖用户自行浏览发现。通过首页弹窗主动推送新素材，提升用户对新效果的知晓率和使用率。
页面说明 · 首页上新弹窗
页面内容
· 首页居中弹窗，背景半透明遮罩 · 效果动画/图片展示区：至少 1 张，至多 4 张自动轮播，切换间隔 3s · 文案区：主标题 + 副标题，区域高度固定 2 行高；仅 1 行文案时居中显示；超长文案自动缩小字号 · 底部「Try」行动按钮 · 右上角 X 关闭按钮 · 素材从云端素材池随机下发（云端配置指定清单，支持新增和删除）
交互说明
· 用户点击「Try」按钮或效果动画区域 → 关闭弹窗 → 跳转选图页（有相册权限直接展示相册；无权限先弹出权限申请） · 选图后： - 单人照片 → 直接进入弹窗对应的效果编辑页，对应效果居中露出并默认选中 - 多人照片 → 先进入人脸选择页，选中人脸后进入效果编辑页，对应效果居中露出并默认选中 · 效果加载：免费效果直接加载；付费效果对非订阅用户不加载，弹出付费拦截弹窗 · 多张素材自动轮播，用户无需手动切换 · 用户点击 X 按钮或弹窗外空白区域 → 关闭弹窗，停留在首页
业务逻辑
xiao g弹出条件 · 看完开屏广告后，用户首次进入首页时弹出 · 新安装用户首次进入首页不弹出 · 每日最多展示 1 次；同一天内未点击弹窗直接退出 App 后再进首页，仍展示弹窗（视为同一次） · 素材资源需全部下载完成后才展示：下载完成时若正在首页则直接弹出；若不在首页则下次启动进入首页时弹出 素材下发规则 · 有更新素材时优先下发；多个更新素材依次下发，每次展示 1 个 · 更新素材全部展示完毕后，从素材池中随机下发，但每 3 次内不重复同一素材 · 同一天内未点击弹窗直接退出 App 后再进首页，展示同一个素材 云控配置 · 弹窗开关：默认关 · 不展示国家：默认所有国家展示（支持多选指定不展示的国家） · 用户订阅状态：所有 / 仅免费 / 仅付费，默认所有 · 安装包类型：所有 / 仅新安装 / 仅升级，默认所有 · 弹窗内效果动画和文案：云控可更新 首页上新弹窗素材（Sheet3）

3.3 Google Play 后台合规问题
问题 1：升级 Google Play Billing Library
Google Play 要求自 2026 年 8 月 31 日起，所有应用必须使用 Google Play Billing Library 8.0.0 或更高版本。需将当前 Billing Library 升级至 8.0.0+，并同步更新所有包含 Billing Library 的第三方 SDK。
问题 2：升级 Target API Level
Google Play 要求自 2026 年 8 月 31 日起，目标 API 级别必须为 Android 16（API 36）或更高。当前不合规的最高目标 API 级别为 Android 15（API 35），需升级至 API 36。
3.4 选图页分类 tab 闪动修复
问题描述
用户从效果编辑页返回选图页时，顶部相册分类 tab 栏出现闪动现象，影响体验流畅度。开发排查并优化该问题。
