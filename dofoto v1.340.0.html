3.2 Collage 编辑页新增 Add 图片
拼图（Collage）编辑页底部工具栏新增「Add」，支持在已有拼图基础上追加图片，分「图上图」与「添加到拼图」两种流程。
流程 1：图上图
① 拼图编辑页，点击 Add
② 弹出「添加到拼图 / 图上图」菜单
③ 选择「图上图」→ 选图页（单选）
④ 返回编辑页，展示已添加图片 + 编辑工具
⑤ 删除该图上图后，仅 Add 高亮，其余工具置灰
· 拼图编辑页底部工具栏新增「Add」 · 点击 Add → 弹出菜单「添加到拼图」/「图上图」 · 选择「图上图」→ 跳转选图页，只能选一张图；若通过相机拍摄，拍完点击 Save 直接返回 Add 编辑页，展示拍照图片 · 返回 Add 编辑页后，展示已添加的图上图图层 + 编辑工具栏 · 若删除该图上图，编辑工具栏中仅「Add」保持高亮可点，其余工具置灰不可用，逻辑与单图编辑页的 Add 一致
流程 2：添加到拼图
① 拼图编辑页，点击 Add
② 弹出菜单，选择「添加到拼图」
③ 图片区域上移，下方展示相册（默认「最近」），选中 1 张
④ 继续点选第 2 张，编辑区域实时同步拼图效果
⑤ 点击 ✅ 确认拼图 → 返回编辑主页，展示最终拼合结果
· 点击「添加到拼图」→ 图片编辑区域上移，下方半屏展示相册选图区，默认选中「最近」分类相册，点击下拉可切换相册 · 相册区域中已选中用于拼图的图片右下角标数字（选中数量），左上角展示「-」按钮 · 点击相册中的图片 → 加入拼图（拼图总数最多 20 张），编辑区域同步展示拼好的拼图效果 · 编辑区域内的拼图图片不可点击拖拽、不可放大预览 · 点击已选图片左上角「-」→ 从拼图中移除该图（拼图总数最少保留 1 张，剩 1 张后不可继续删除） · 点击右上角 ✅ 确认拼图 → 返回编辑主页
3.3 Filter 编辑页新增 Adjust 分类
Filter 浮层底部新增「ADJUST」一级分类，与「FILTER」并列，用户应用完滤镜效果后无需退出当前浮层，可直接切换到 Adjust 调整亮度 / 对比度等其他参数。
页面说明
页面内容
· Filter 浮层底部新增「ADJUST」一级分类，与「FILTER」并列展示
交互说明
· 点击底部「ADJUST」→ 切换到调节面板，可调整亮度 / 对比度等参数 · 点击「FILTER」→ 返回滤镜列表，当前选中效果保留
业务逻辑
参数保留规则 · 用户在 Filter（任意分类）与 Adjust 之间切换时，各分类下已调整的参数分别保留，互不覆盖 · 返回任一分类后支持继续调节，调节结果实时叠加在当前预览上
3.4 Filter 新增 Camera 滤镜分类
Filter 新增「Camera」分类，收录 7 款胶片相机风格滤镜：LUMIX S9、Fujifilm、Fuji_NC、LEICA Q2、GR3、KODAK、CANON AE1。
业务逻辑
分类位置与内容 · Filter 分类新增「Camera」一级 tab，位于「Film」之后（第 4 位） · 收录效果：LUMIX S9、Fujifilm、Fuji_NC、LEICA Q2、GR3、KODAK、CANON AE1，共 7 款 · 缩略图复用 Uface 现有「相机」分类的相机图标样式 解锁与预览 · 保存方式：订阅后才能保存（非会员不可保存 Camera 分类效果结果） · 支持点击效果缩略图直接预览，非会员点击预览时弹出订阅卡片
§4 关注指标及决策框架
关注指标
指标名称作用分子分母备注
Face 编辑完成率 护栏：监控新 SDK 是否影响编辑体验 完成一次 Face 编辑并保存的用户数 进入 Face 编辑页的用户数 对比切换前基线
新增效果使用率 主指标：衡量新增调节效果（Smiley/Outer/Philtrum 等）的用户接受度 使用过新增效果的用户数 进入 Face 编辑页的用户数 —
Collage Add 使用率 主指标：衡量新功能的曝光触达与使用意愿 点击 Add 并完成添加的用户数 进入 Collage 编辑页的用户数 按图上图 / 添加到拼图分别统计
Adjust 切换率 主指标：衡量 Filter/Adjust 整合的使用效果 Filter 浮层内点击 Adjust 的用户数 进入 Filter 浮层的用户数 —
Camera 滤镜订阅转化率 主指标：衡量 Camera 分类对订阅转化的拉动 点击 Camera 滤镜后完成订阅的用户数 点击 Camera 滤镜的用户数 —
决策框架
指标结果对本需求价值判断后续方向
Face 编辑完成率持平或提升，新增效果使用率达预期 ✅ SDK 切换与新增效果均达成预期 评估进一步扩充调节效果
Face 编辑完成率下降 ❌ 新 SDK 影响编辑体验 排查具体 Tab / 效果的问题，评估是否需要临时下线
Collage Add 使用率低 ⚠️ 曝光或易用性不足 优化 Add 入口视觉与两种流程的引导
Adjust 切换率达预期 ✅ Filter/Adjust 整合有效 维持现状，观察长期留存
Camera 滤镜订阅转化率达预期 ✅ 新滤镜对订阅有拉动 持续扩充 Camera 分类滤镜数量
